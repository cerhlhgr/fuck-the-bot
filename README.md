# Telegram-бот для ответов на @упоминания

Бот читает сообщения через long polling и сохраняет короткие тексты переписки за последние 24 часа в PostgreSQL. Если в тексте или подписи есть упоминание его `@username`, он отправляет в Timeweb AI (`deepseek/deepseek-v4-pro`) прежний диалог из того же чата и темы, разбирает JSON вида `{"reply":"..."}` и публикует ответ реплаем. На обычные сообщения и упоминания других ботов он не отвечает, но сохраняет их для контекста.

## Запуск через Docker Compose

1. Создайте бота через [@BotFather](https://t.me/BotFather). Чтобы бот видел всю переписку группы, отключите у него **Group Privacy Mode** через `/setprivacy` в BotFather или назначьте его администратором. Если вы отключили privacy mode уже после добавления бота, удалите его из группы и добавьте заново.
2. Скопируйте `.env.example` в `.env` и задайте в нём `TELEGRAM_BOT_TOKEN` и `TIMEWEB_AI_API_KEY`.
3. Запустите `docker compose up -d --build` и напишите в группе `@имя_бота привет`.

Compose запустит бота и PostgreSQL. База сохраняется в Docker volume `postgres_data`; для подключения с хоста она доступна на `127.0.0.1:25432` (порт можно изменить через `POSTGRES_PORT`) с учётными данными из `compose.yaml`. Это локальная конфигурация. Для внешней базы запустите Go-процесс отдельно со своим `DATABASE_URL`.

## Запуск Go-процесса отдельно

Поднимите PostgreSQL (`docker compose up -d db`) или используйте существующий сервер, затем задайте переменные окружения:

```sh
export TELEGRAM_BOT_TOKEN='токен_от_BotFather'
export TIMEWEB_AI_API_KEY='ключ_Timeweb_AI'
export DATABASE_URL='postgres://bot:bot-local@127.0.0.1:25432/bot?sslmode=disable'
# Необязательно:
export AI_MODEL='deepseek/deepseek-v4-pro'
```

Запустите `go run .`.

При первом запуске бот сам создаёт таблицу `bot_history` и индексы. Записи старше 24 часов удаляются при работе бота; прежнюю историю Telegram через Bot API не выдаёт. Для экономии контекста каждая реплика сокращается до 320 символов, а в один запрос попадают не более 80 последних реплик и 12 000 символов. Переписки разных чатов и тем не смешиваются. При включённом privacy mode Telegram доставит боту лишь часть сообщений, поэтому контекст будет неполным.

Если у бота настроен webhook, удалите его через Bot API до запуска long polling. Одновременно запускайте только один экземпляр бота с одним Telegram-токеном.

Проверка: `go test ./...`. Для проверки SQL на запущенной тестовой базе: `TEST_DATABASE_URL='postgres://bot:bot-local@127.0.0.1:25432/bot?sslmode=disable' go test ./...`.
